# The Next 60 — Mini-site

מיני-סייט תדמיתי דו-לשוני (עברית/אנגלית) עבור מותג **The Next 60** — דיור בוטיק יוקרתי לגיל 60+.

## Live preview
- **GitHub Pages**: https://hiyabh.github.io/next60-minisite/

## הפרויקטים המוצגים
- **הוד דניה** — דיור מוגן יוקרתי בקריית היובל, ירושלים (פעיל)
- **Embassy Court** — דיור בוטיק בקונספט עיצובי ייחודי (בשיווק)
- **הוד ירושלים** — הפרויקט המייסד (מורשת)

## טכנולוגיה
- HTML5 + inline CSS3 + Vanilla JS (ללא frameworks, ללא build step)
- 11 תמונות, סה"כ 2.2MB
- RTL/LTR דינמי
- IntersectionObserver לאנימציות סקרול
- נגישות לקהל 60+ (פונט 18px, ניגודיות גבוהה, focus rings, ARIA labels)

## מבנה
```
index.html        — כל הסייט בקובץ אחד
assets/           — לוגו + 10 תמונות פרויקטים
```

## פיתוח
פתחו את `index.html` ישירות בדפדפן (לא נדרש שרת).
